# FlowParity project conventions

- This is an independent, offline Codex skill + Python 3.10+ helper. No paid APIs, scraping, hidden server, or app clone generator.
- Read relevant repo docs and inspect `git status` before edits. Preserve user's changes. Use native implementation and minimal dependencies.
- Run `python -m unittest discover -s tests -v`, `python -m compileall -q src`, `git diff --check` where applicable.
- Keep evidence claims limited to observed tests; mark unrun Windows/Codex acceptance NOT_VERIFIED.
- Maintain English and Russian documentation together. Never publish private app research, screenshots or credentials.
- Make readable local Git commits when authorized. Never push, merge or publish without explicit request. Stop once acceptance criteria are met.
