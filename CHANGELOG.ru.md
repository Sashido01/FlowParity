# Журнал изменений

## 0.0.1 — 2026-11-02

- Запрещена запись реестра через Windows reparse points, включая junction в Python 3.10; добавлена регрессионная проверка junction для Windows.
- Проверка Windows reparse attributes ограничена Windows после обнаружения конфликта с битами POSIX в Ubuntu CI; CI actions обновлены до текущих Node 24-релизов с проверенными полными SHA.
- Существующий публичный коммит README восстановлен как основа локальной истории; завершена двуязычная документация выпуска.

## 0.0.0 — 2026-11-02

- Добавлен оригинальный нативный навык Codex `flow-parity` с краткими справочниками по правам доступа, исследованию, QA и интеграции.
- Создана автономная JSON CLI с проверкой синтаксиса, ссылок, покрытия функций, записанного допуска к выпуску и генерацией идей тест-кейсов.
- Добавлены тесты, синтетический пример, двуязычная документация, локальная история Git и конфигурация CI для Windows/Ubuntu.
- Границы: функциональный анализ и организация доказательств, но не автоматический клонировщик приложений, юридическая сертификация или E2E-тестовый движок.
