# Безопасность

Не публикуйте сведения об эксплуатируемых уязвимостях и секретах в открытых GitHub Issues. Используйте форму **Security → Report a vulnerability** для приватных сообщений. Если она недоступна, свяжитесь с сопровождающим через опубликованный им приватный канал; вымышленных адресов здесь нет.

CLI работает офлайн, не запускает shell и сетевые команды, не перезаписывает существующие реестры. Но она не создаёт полноценную песочницу, не проверяет внешние файлы доказательств, не устраняет все файловые гонки и не сертифицирует приложение. Не запускайте её на недоверенном репозитории с повышенными привилегиями.

Сторонние приложения допускается изучать только в пределах прав владельца или публично доступных сведений. Проверка безопасности чужого сервиса требует отдельного разрешения. QA выполняется на локальной реализации, секреты и приватные исследования — вне Git.
