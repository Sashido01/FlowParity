# Provenance and independent implementation

FlowParity is an original implementation tailored for native OpenAI Codex and the user's existing development stacks. The product idea was informed by publicly documented concepts in [Jakeschincariol/replica-skill](https://github.com/Jakeschincariol/replica-skill) (MIT): user-flow reconnaissance, feature parity, test evidence and original rebranding. The source project's eleven Claude skills were **not** copied into this repository; all FlowParity Python logic, manifest schema, tests and written instructions were newly authored here. Its license file remains with the upstream, not embedded as reused source content.

Design sources additionally consulted:
- [OpenAI: skills and AGENTS.md workflows](https://developers.openai.com/blog/skills-agents-sdk)
- [OpenAI: keeping skills and prompts concise](https://developers.openai.com/blog/rethinking-skills-and-prompts-for-gpt-6-astra)
- [GitHub Actions secure use](https://docs.github.com/en/actions/reference/security/secure-use)

This is not a legal finding about independent functionality, brand rights, or third-party terms; review licenses, trademarks, trade dress and terms before implementing a commercial app.
