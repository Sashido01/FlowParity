# Участие в разработке

Открывайте конкретный Issue: проблема, воспроизведение, ожидаемое поведение и границы изменений. Не включайте закрытые материалы сторонних приложений, скриншоты с персональными данными, ключи или сведения о частных целях. Вклад должен быть самостоятельной работой либо материалом с законным основанием и совместимой лицензией.

Используйте Python 3.10+ и стандартную библиотеку. Запускайте `python -m unittest discover -s tests -v` и `python -m compileall -q src`, добавляйте регрессионные тесты. Обновляйте русские и английские документы вместе. Предпочтительны небольшие содержательные коммиты. Успешный gate JSON не означает готовность к выпуску.

Все PR проходят проверку сопровождающего; открытие PR не означает разрешение на публикацию в рабочем сервисе.
