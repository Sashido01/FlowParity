# Integrate without replacing the native stack

**Codex:** project skills live at `.agents/skills/<name>/SKILL.md`. Check host Codex's current skill discovery. Installed metadata does not by itself prove auto-activation. Use `$flow-parity` for explicit invocation. Keep global settings intact.

**Existing project policy:** `AGENTS.md`, accepted architecture decisions, test scripts, logging, and scope ownership take priority. If ScopeAnchor already governs completion, reuse it; FlowParity owns feature/flow evidence only. Do not store the same plans twice.

**HTML5 / Node / games (YAPLIX-type):** test game generation and running exported HTML in the actual project harness; inspect mobile responsive flow, local QR/LAN assumptions, persistence, and runtime errors. Do not assume browser/webGL parity from screenshots.

**Rust / Slint / SQLite (REVIZYUM-type):** preserve native Slint UI, Cargo tests and database migrations. Test real import and voice confirmation boundaries; never auto-accept uncertain OCR/ASR data.

**Windows / PowerShell and desktop (YARVIS-type):** preserve signed/native OS control and actual GUI; do not substitute browser windows or change user profile credentials. Prefer the project's own diagnostics and explicit data boundaries.

**Source of truth:** use the files and tests the project already maintains. Choose minimal targeted changes, independently verified results, real logs and readable local Git commits. Do not install Playwright, dependencies or network tools unless the host project needs them and the user authorized the change.
